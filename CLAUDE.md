Public Android library for SEDAP Express, based on the Java reference `UNIITY-Team/SEDAP-Express`.

**This repository is public.** Commit nothing project-specific: no server addresses, passwords, exercise data or references to private projects.

If the sibling folder `../SAC2-Orchestration` exists, read its `CLAUDE.md` and `LIB.md` first. Plans and requirements live there and are not copied here.

Keep changes under `upstream/` to an absolute minimum, each marked `// ANDROID-PATCH:` and listed in `PATCHES.md`.
